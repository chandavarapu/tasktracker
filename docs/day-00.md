# Day 0 — What I'm building and why

**What I did today:** Set up my development environment and
learned how a web application actually works.

**What I learned:** Every web app is three things. A client
that draws the interface, a server that holds the rules, and
a database that remembers. When I click a button the browser
sends a request to the server, the server checks it and talks
to the database, and the answer comes back the same way.

**What surprised me:** I have two servers, not one. Next.js
serves the interface and FastAPI holds the logic. I thought
"the backend" was a single thing.

**What I'm building:** A task tracker that will grow a full
CI/CD pipeline, three environments, an AI feature with
retrieval and evaluation, a data pipeline, and monitoring.
One system, not fifteen demos.

**Tomorrow:** Designing my first database table.
